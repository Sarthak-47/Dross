Build it · wire it into your agent

Get to work

Requires Rust 1.88+. Prebuilt CLIs and desktop installers are on the releases page.

# build from source — nothing leaves your machine
git clone https://github.com/Sarthak-47/Dross.git
cargo build --release

# check what you're about to commit
dross check --staged

# build the whole-repo index, then find clones
dross index
dross check --worktree

✓ clean — 34 file(s), 41ms · no network calls · 0 bytes sent

On trust

The binaries are unsigned — there is no paid certificate behind this project, so Gatekeeper and SmartScreen will warn on first run. That warning is accurate; don’t wave it away on the strength of a landing page.

Instead, every release asset carries signed build provenance you can verify:

gh attestation verify dross-… --repo Sarthak-47/Dross

It proves the file came from this repo’s CI at a commit you can read. Building from source needs no trust at all.
